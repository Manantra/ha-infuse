# Security Policy

For security issues, use [GitHub private vulnerability reporting](https://github.com/Manantra/ha-infuse/security/advisories/new), where available.

Do not disclose exploitable weaknesses, access credentials, device addresses or private media URLs in public issues.

The Firecore Now Playing API is unauthenticated local HTTP. It must remain on a trusted LAN, not exposed by port forwarding or public proxies.
